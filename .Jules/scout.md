## 2024-05-23 - Reliability Refactor: Snapshot Logic **Risk:** Snapshot comparison logic was tightly coupled with `SpreadsheetApp` (in `compareSnapshots`), making it impossible to test without a live Google Sheet and susceptible to silent regressions if data formats changed. **Prevention:** Extracted the core math into a pure function `calculateSnapshotDiff(snapshot1, snapshot2)` in `Code.js`. Added a local Node.js unit test `tests/test_calculateSnapshotDiff.js` (using `vm` to load the GAS code) and a server-side GAS test `Tests.gs` to ensure consistent behavior across environments. Testing revealed that `const` variables in GAS files need explicit handling when loaded into Node `vm` contexts.
