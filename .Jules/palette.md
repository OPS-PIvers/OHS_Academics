## 2024-05-22 - Tailwind Configuration in Google Apps Script **Learning:** When using the Tailwind CSS Play CDN in a GAS environment, the configuration script (`tailwind.config = {...}`) must be placed **after** the CDN script tag. If placed before, `window.tailwind` is undefined, and the configuration is ignored, causing brand colors to fail silently. **Action:** Always verify the script order: CDN first, then Config. Also, verify color application using `getComputedStyle` in Playwright to catch invisible elements.
