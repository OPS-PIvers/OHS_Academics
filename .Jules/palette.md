## 2026-01-03 - [Tailwind Runtime Configuration] **Learning:** Defining custom colors in the Tailwind runtime configuration (script block) requires quoted keys for kebab-case names (e.g., 'blue-dark') but not for camelCase. However, using 'ops-primary' as a class requires defining the color key as 'primary' under the 'ops' object. **Action:** Always quote non-standard keys in JSON-like configuration objects within HTML script tags.
