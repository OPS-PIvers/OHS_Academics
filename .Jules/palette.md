## 2024-01-20 - Enforcing OPS Tech Brand with Tailwind **Learning:** Tailwind CDN configuration allows extending the theme to enforce brand colors and fonts globally. Setting `fontFamily.sans` to `['Lexend', 'sans-serif']` in the config ensures all text inherits the brand font without individual class changes. **Action:** Use inline `tailwind.config` script for quick, global brand alignment in projects without a build step.
