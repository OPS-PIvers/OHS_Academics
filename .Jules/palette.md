# Palette's Journal

## 2024-05-22 - Brand Misalignment Detected
**Learning:** The project was using the "Inter" font and standard Tailwind colors (e.g., `bg-blue-600`), which deviate from the OPS Tech Brand Guidelines (Lexend font, #2d3f89 Primary Blue).
**Action:** Always check `index.html` for font imports and hex codes immediately. Creating a standard CSS block for OPS colors will make future updates easier.
