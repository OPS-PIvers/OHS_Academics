## 2024-05-22 - Brand Alignment Enforcement **Learning:** Directly injecting a runtime `tailwind.config` object is the most effective way to enforce strict brand colors in a CDN-based Tailwind environment without a build step. **Action:** Always look for and replace generic color classes (e.g., `bg-blue-600`, `text-purple-600`) with the defined `ops-*` utilities to ensure visual consistency.
