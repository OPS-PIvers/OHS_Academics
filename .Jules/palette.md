## 2024-02-14 - Tailwind Runtime Config for GAS **Learning:** In a CAS environment where we cannot run a build step, `tailwind.config` can be set via a runtime script tag to inject custom brand colors and fonts. **Action:** Use `<script>tailwind.config = { ... }</script>` before the Tailwind CDN script to enable utilities like `bg-ops-primary`.

## 2024-02-14 - Playwright Environment **Learning:** The node environment lacks the `playwright` package, but `playwright` is available in the python environment. **Action:** Use Python scripts for Playwright verification tasks.
